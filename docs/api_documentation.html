1. AUTHENTICATION & OVERVIEW

Base URL

http://108.181.193.242:8080/api

Authentication

All protected endpoints require a JWT Bearer token in the Authorization header:

Authorization: Bearer <access_token>

Getting a Token

POST /api/auth/login
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "password123"
}

Response:
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "user": {
    "id": "uuid",
    "username": "user",
    "email": "user@example.com",
    "isAdmin": false,
    "coins": 100
  }
}

Rate Limiting

EndpointLimit
Global100 requests / 60 seconds
POST /auth/register3 requests / hour
POST /auth/login5 requests / minute
POST /auth/2fa/*3 requests / minute

Error Response Format

{
  "statusCode": 401,
  "message": "Invalid credentials",
  "error": "Unauthorized"
}

Auth Levels

LevelDescription
PUBLICNo authentication required
USERValid JWT token required
ADMINValid JWT + is_admin=true required

2. AUTH MODULE

POST /api/auth/register PUBLIC
Register a new user account
Body: { email, username, password, first_name?, last_name? }
Response: { message, userId }
POST /api/auth/login PUBLIC
Login with email/username and password
Body: { email, password }
Response: { access_token, user } OR { requires2FA, email } OR { requiresEmailVerification, email }
POST /api/auth/login-2fa PUBLIC
Complete login with 2FA code
Body: { email, code }
Response: { access_token, user }
GET /api/auth/me USER
Get current user profile
Response: { id, username, email, coins, isAdmin, profilePhoto, ... }
PUT /api/auth/me USER
Update current user profile
Body: { username?, email?, first_name?, last_name? }
POST /api/auth/profile/photo USER
Upload profile photo (multipart/form-data)
Body: file (image/jpeg, image/png, max 5MB)
POST /api/auth/setup-admin PUBLIC
Create first admin account (requires setup key)
Body: { setupKey, username, email, password }

2FA Endpoints

POST /api/auth/2fa/generate USER
Generate 2FA secret and QR code
Response: { secret, qrCodeUrl }
POST /api/auth/2fa/enable USER
Enable 2FA with verification code
Body: { code }
POST /api/auth/2fa/disable USER
Disable 2FA
Body: { code }
POST /api/auth/2fa/check PUBLIC
Check if email has 2FA enabled
Body: { email }
Response: { requires2FA: boolean }
