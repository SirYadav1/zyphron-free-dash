## findings

ZY-14 · medium
no password reset existed at all. a user who lost the password was stuck.
`fd893b9` adds the otp flow: 6 digits, 10 minute expiry, bcrypt hash stored in
`password_resets`, 3 requests per 15 minutes.
the otp comes from `Math.random()`, fixed on the 21st (ZY-23).

ZY-15 · medium
`scripts/backup.sh` tars `.env` and `zyphron.db` into `/root/backups`, no encryption,
no passphrase. the archive is a full credential dump. still open at release.

ZY-16 · high
`AdminGuard` only checked `user.is_admin`. roles created through the roles module
(owner, staff) did not grant access, and in two modules the guard resolved to nothing
so the route was open.
`5b22215` adds the role lookup, `94294ee` moves the guard into a shared module using
`DataSource` so it resolves everywhere.
retest: staff hits `GET /api/admin/users` -> 200, non-staff -> 403.

ZY-17 · low
mail module had a circular dependency (`EmailTemplateHelper` and `MailService`), which
broke the module on a cold boot. `e053c43` fixes the injection order.

ZY-18 · low
`EncryptionUtil` throws when `ENCRYPTION_KEY` is missing, and `.env.example` does not
list it. a fresh deploy that saves an smtp password breaks the mailer with a stack
trace. still open at release.

## closed today

the key is sha256 of `ENCRYPTION_KEY`. `isEncrypted()` keeps old plain rows readable,
so existing settings do not need a migration.
retest: save smtp password, read the row -> `enc:...`, send a test mail -> ok.
