# 2026-06-15

first day. the whole platform went in as one commit (`08fb2a7`), then straight into
fixes. 8 commits, one of them a security pass.

## findings

ZY-01 · medium
login was throttled at 10 requests a minute and that was it. no lockout, no
per-account counter, so guessing a password was cheap.
`c1e9418` -> 5/min on login, 3/min on register and 2fa.
retest: six bad POSTs to `/api/auth/login` in a row, the sixth returns 429.

ZY-02 · medium
register accepted 6 characters, no complexity rule at all.
`c1e9418` -> min 8, needs upper + lower + digit.
retest: POST with `aaaaaaaa` -> 400.

ZY-03 · medium
username had no charset restriction, `@MinLength(3)` and nothing else.
`c1e9418` adds `^[a-zA-Z0-9_]+$`.

ZY-04 · low
`X-Powered-By: Express` on every response. free fingerprinting.
`c1e9418` -> `app.disable('x-powered-by')`.

ZY-05 · low
CSP had `script-src 'self' 'unsafe-inline'`. vue + vite don't need inline script.
`c1e9418` strips it. `'unsafe-eval'` is still in the header, noted for later.

ZY-06 · low
nginx had `autoindex on` and a duplicated server block, both live on the box.
fixed by hand in `nginx.conf`, nothing to diff. the repo has no nginx config at all,
which is the real problem.
