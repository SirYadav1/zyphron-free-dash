# 2026-06-21

last day of the sprint. 5 commits, three of them security. went through the api key,

## findings

ZY-22 · medium
the "your password was changed" mail included the new password in the body.
`1fd04ad` drops it, the mail only says the password changed.
retest: reset a password, read the mail -> no credentials in it.

ZY-23 · medium
reset otp came from `Math.random()`, 6 digits, predictable.
`1fd04ad` -> `crypto.randomInt(100000, 999999)`.

ZY-24 · medium
discord oauth state lived in a process-local map. a restart or a second pm2 worker
dropped the state and the callback then failed open to replay.
`fe7dd24` stores state in the db with an expiry.
retest: start the flow, restart the backend, finish it -> still works.

ZY-25 · medium
admin coin edit had no ceiling, a typo could set the balance to anything.
`08691f5` -> `MAX_COINS = 10_000_000`.

ZY-26 · high
server name went to pterodactyl and into the db unfiltered.
`08691f5` strips tags and control chars and enforces `[a-zA-Z0-9_-]{3,32}`.
retest: name `<img src=x onerror=alert(1)>` -> stored as `img-src-x-onerror-alert-1`.

ZY-27 · high
profile upload trusted `Content-Type`. a php file renamed to `.png` passed.
`08691f5` reads the first 8 bytes and checks jpeg/png/gif/webp signatures, deletes
the file when it does not match.
retest: upload a text file named `x.png` -> 400, file removed from uploads.
